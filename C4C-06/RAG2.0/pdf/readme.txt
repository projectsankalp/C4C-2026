Place any PDF, DOCX, PPTX, image, or audio files in this folder.
Whenever you run `py rag_server.py`, the system will automatically:
1. Detect all files in this folder.
2. Ingest, OCR, or transcribe them.
3. Index them into the Global Shared Archive so they are accessible to all users.
4. Clean up this folder automatically by purging the source files.
