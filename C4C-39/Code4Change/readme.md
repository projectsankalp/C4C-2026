# CredOra — Skill Passport for Women in India’s Unorganized Sector

**Empowering women with voice-first skill recognition, verifiable digital passports, and direct employment opportunities.**

## The Problem
Millions of skilled women working as domestic helpers, tailors, artisans, construction workers, and beauticians have **no proof** of their skills. This leads to low wages, exploitation, and limited access to better jobs and schemes.

## The Solution
**CredOra** is a **voice-first Progressive Web App** that allows women to:

- Record their skills in their native language
- Get instant AI assessment + NSQF level
- Receive a **verifiable digital passport** with QR code
- Access personalized government schemes & training (**CredOraLink**)
- Connect directly with employers through **CredOraHire** — a trusted hiring pipeline with product evaluation and verified reviews

## Key Features

- **Voice-First Assessment** — Speak in Hindi, Tamil, Kannada, Telugu, Bengali, or English
- **Digital Skill Passport** — Shareable profile with video proof
- **CredOraLink** — Smart recommendations for government schemes using web scraping + AI
- **CredOraHire** — Companies request physical product samples → Evaluate → Hire with confidence
- **Offline-First PWA** — Works on low-end phones with poor internet
- **6 Indian Languages** supported

## Tech Stack

- **Frontend**: Next.js 14 + TypeScript + Tailwind CSS + PWA
- **Backend**: FastAPI + Supabase + PostgreSQL
- **AI**: Sarvam (STT/TTS), Groq, GLM 5.1, Nemotron (Vision)
- **Unique**: Live government scheme scraping + Physical product evaluation system

## Target Impact
- Help women increase income by ₹4,000–10,000 per month
- Reduce hiring risk and time for employers
- Bridge informal workers with formal opportunities
